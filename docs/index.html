ArgumentTypeDefault valueMenu choices

connect to HTTP bridge

Opens a WebSocket connection to the configured HTTP bridge server.

This block has no arguments.

固定入力の編集

対応GUIの固定入力機能は既定OFFです。既存値は開いただけでは変更せず、reporter接続は評価・置換しません。新しい選択と有限JSON数値入力のみを検証して保存し、既存の補正・丸め処理を維持します。機能OFFで従来の編集へ戻せます。
